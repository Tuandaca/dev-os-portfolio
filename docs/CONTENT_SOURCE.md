A repository URL is shown only where verified and safe; the Travel AI source link remains absent. A live demo URL requires a reachable page whose visible identity is consistent with the repository. Runtime HTTP checks establish reachability only, not the deployed commit or achieved outcomes.

Before linking GymLVL and the business repositories, a focused credential check inspected their pinned-commit file trees for `.env`, credential, private-key, and related filenames; business roots, READMEs, and manifests; GymLVL `README.md`, `app/lib/core/config/supabase_config.dart`, and the sole `.npmrc` template at `supabase/functions/switch-class/.npmrc`. GitHub code search did not return even expected benign matches, so this is **not** an exhaustive repository secret scan. The Travel AI credential concern remains separate and unresolved.
